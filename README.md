# To-Do List Application

**Name:** Tayab

## Description

This is a simple browser-based to-do list application. Users can add tasks, choose a priority level, mark tasks as complete, change a task’s priority after adding it, and delete tasks.

Tasks are visually organized by priority:

- Low priority tasks use a green priority label.
- Medium priority tasks use a yellow priority label.
- High priority tasks use a red priority label.
- Completed tasks are grayed out and shown with a line through the task text.

## How to Run

1. Download or clone the project files.
2. Make sure `index.html`, `style.css`, and `script.js` are in the same project folder.
3. Open `index.html` in a web browser.
4. Enter a task, choose a priority, and click **Add Task**.

No installation, server, or external dependencies are required.

## Known Problems / Incomplete Features

- Tasks are not saved after refreshing or closing the browser.
- There is no filter for viewing active versus completed tasks.
- Tasks cannot be edited after being created; only their priority can be changed.
- The application does not currently support due dates, categories, or task sorting.
